# kgalias — 知识图谱别名投影库

进程内 Go 库，由上层分析流程直接调用（无接口层）。文档提及、别名版本与图谱状态全部保存在内存中，图谱始终等同于使用当前文档与当前别名版本从头构图的结果。

## 构建与测试

```sh
go build ./...        # 编译
go test ./...         # 全部测试（含规模验证，约 20s）
go test -short ./...  # 跳过规模验证
go test -run TestScale -v ./...  # 只跑规模验证
```

## 数据模型

- `Document{ID, Sentences}`：稳定编号 + 按序句子，每句是该句的别名提及列表（可重复）。
- `AliasVersion{ID, Bindings}`：完整别名版本，`别名 -> 实体编号`；未绑定别名不参与图谱；版本登记后不可修改。
- 实体：至少在 一篇当前文档中出现的实体形成节点，文档频次按文档去重。
- 边：两个不同实体的提及同句或句距 ≤ 2 即产生一条无向边；同一文档对同一边只贡献一次支持；无自环。
- 置信度：`支持文档数 / sqrt(两端文档频次乘积)`。

## 调用示例

```go
g := kgalias.NewGraph()

// 提交并启用别名版本（重复 ID 会 panic）
g.SubmitVersion(kgalias.AliasVersion{
    ID:       "v1",
    Bindings: map[string]int64{"甲": 1, "乙": 2},
})

// 新增 / 整体替换 / 删除文档（重复提交相同内容不增加计数）
g.AddDocument(kgalias.Document{ID: 100, Sentences: [][]string{{"甲", "乙"}, {"甲"}}})
g.DeleteDocument(100)

// 切换到已登记版本（未登记 ID 会 panic）；只重投影绑定变化影响的文档
g.SwitchVersion("v2")

// 邻居查询：节点频次 + 置信度 >= 0.5 的邻边（含支持数）
info := g.Node(1) // NodeInfo{Entity, DocFreq, Edges}

// 完整支持文档编号集合（不受置信度阈值影响），升序返回
docs := g.SupportDocs(1, 2)
```

## 实现要点

- 每篇文档独立投影为「实体集合 + 边集合」并缓存；文档增删改只做该文档的增量反投影/重投影。
- 版本切换按绑定差异定位受影响别名，经「别名 -> 文档」倒排索引只重投影相关文档。
- 边支持集合、实体文档频次、实体邻接索引随投影增量维护，邻居查询为 O(度数)。

## 规模验证（TestScale，本机 Go 1.27 / Apple Silicon）

- 10 万篇文档、200 万次提及、2 万个别名。
- 单绑定差异的版本切换：P95 ≈ 1ms（要求 ≤ 100ms）。
- 语料 1 万 → 10 万篇后，相同切换耗时中位数基本不变（要求 ≤ 3 倍）。
- 邻边 ≤ 100 的节点邻居查询：P95 亚微秒级（要求 ≤ 30ms）。
