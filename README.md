# kgalias — 知识图谱别名投影库

在进程内存中维护文档、别名版本与图谱状态，供上层分析流程直接以 Go 库形式调用。
每次修改返回后，所有查询都等价于使用当前文档和当前别名版本从头构图；
版本切换与文档增删改均按受影响范围增量重算，不重建整个语料库。

## 数据模型

- 文档以稳定编号（`DocID`）标识，输入为按顺序排列的句子，每句是一个别名提及列表。
- 别名版本（`VersionID`）是一组完整的 `别名 → 实体编号` 绑定，登记后不可修改；
  允许多个别名绑定同一实体，未绑定的别名不参与当前图谱。
- 实体在当前文档中至少出现一次即形成节点；文档频次按不同文档计数，
  同一文档中的重复提及与多个别名只计一次。
- 两个不同实体的任意提及位于同一句或句距不超过 2 时，该文档支持一条无向边；
  同一文档对同一条边只贡献一次支持，不产生自环。
- 边置信度 = 支持文档数 / sqrt(两端文档频次之积)。

## 调用示例

```go
g := kgalias.NewGraph()

// 登记不可修改的别名版本（重复登记返回 ErrVersionExists）
_ = g.RegisterVersion("v1", map[kgalias.Alias]kgalias.EntityID{
    "阿司匹林": 1, "阿斯匹林": 1, "布洛芬": 2,
})
_ = g.ActivateVersion("v1") // 未登记的版本返回 ErrVersionNotFound

// 新增或整体替换文档（重复提交相同内容不改变任何计数）
g.UpsertDocument("doc-1", [][]kgalias.Alias{
    {"阿司匹林", "布洛芬"}, // 句 0
    {"阿斯匹林"},           // 句 1，与句 0 句距 1
})
g.DeleteDocument("doc-1") // 删除文档

// 查询
freq := g.DocumentFrequency(1)   // 节点文档频次
res := g.Neighbors(1)            // 节点频次 + 置信度 ≥ 0.5 的邻边
docs := g.SupportDocuments(1, 2) // 完整支持文档编号集合（不受阈值影响）
_ = freq; _ = res; _ = docs

// 切换别名版本：只重算绑定变化的别名所涉及的文档
_ = g.RegisterVersion("v2", map[kgalias.Alias]kgalias.EntityID{
    "阿司匹林": 1, "阿斯匹林": 9, "布洛芬": 2, // 拆分误合并的实体
})
_ = g.ActivateVersion("v2")
```

## 实现要点

- `projection.go`：单文档在当前绑定下的贡献（实体集合 + 实体对集合），窗口大小为 2。
- `graph.go`：文档倒排索引（别名 → 文档，与版本无关）、实体/边的支持文档集合，
  以及增删改与版本切换的增量重算。切换版本时仅对绑定发生变化的别名，
  通过倒排索引定位受影响文档，逐篇移除旧贡献并按新绑定重算。
- `query.go`：文档频次、邻居查询（按置信度 0.5 过滤）、完整支持文档集合。

## 测试与规模验证

```sh
go test ./...        # 全部测试，含规模验证（约 25 秒）
go test -short ./... # 仅正确性测试，跳过规模验证
```

- 正确性：重复提及、重叠窗口、句距 2/3、幂等替换、置信度随频次变化、
  合并/拆分/解绑与文档增删改穿插、版本不可变，以及 400 步随机混合操作
  逐步与朴素全量重算对照（`graph_test.go`）。
- 规模验证（`scale_test.go`，本机 Go 1.27 / Apple Silicon 实测）：
  - 10 万文档、200 万提及、2 万别名，仅一条绑定不同（涉及别名出现在 20 篇文档）
    的版本切换 P95 ≈ 2.6ms（要求 ≤ 100ms）；
  - 语料从 1 万扩至 10 万且新增文档与切换无关时，切换耗时中位数倍率 ≈ 1.01（要求 ≤ 3）；
  - 具有 98 条原始邻边、200 篇支持文档的节点，邻居查询 P95 ≈ 38µs（要求 ≤ 30ms）。
